# Cookbooks

Each cookbook is one goal, from start to finish, built from kia's pieces. The other docs explain each piece in detail; these show how they fit together.

- [A home TV box: kia, Threadfin, and Plex in containers](plex-box.md). One computer runs everything, and Live TV appears in every Plex app, next to your own movies and shows.
- [Kodi and kia on one computer](kodi-computer.md). A laptop or desktop finds free channels, builds their guide, and plays them in Kodi, with nothing else to set up.
